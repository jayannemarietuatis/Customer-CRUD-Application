# Customer Management CRM - Code Challenge

This is a simple CRUD application for managing customer records, built with **Lumen/Laravel** (Backend) and **Angular 7+** (Frontend). The system is fully containerized using **Docker** and uses **Elasticsearch** for search synchronization.

## Features
- Create, Update, Delete, List, and View Customers.
- Real-time synchronization to **Elasticsearch**.
- Search customers by Name and Email.
- Containerized architecture (4 services).

## Tech Stack
- **Backend:** Lumen/Laravel
- **Frontend:** Angular 7+ / Bootstrap
- **Search Engine:** Elasticsearch
- **Database:** 
- **Orchestration:** Docker Compose

## Prerequisites
Before running the application, ensure you have the following installed:
- Docker and Docker Compose
- Git
